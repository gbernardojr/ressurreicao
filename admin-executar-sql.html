Configurar Tabela de Admins

Esta página configura a tabela admin_usuarios com as permissões necessárias para o gerenciamento de administradores pelo app.

Instruções

  1. Clique no botão "Copiar SQL" abaixo
  2. No painel do Supabase, vá em SQL Editor
  3. Cole o SQL na área de edição
  4. Clique em "Run" (botão verde)
  5. Repita para o Script 2 (se necessário)

Após executar o SQL

1. Vá em Table Editor → admin_usuarios
2. Adicione o registro do admin com nome, email e CPF
3. No app, acesse o painel admin e teste "Gerenciar Administradores"
